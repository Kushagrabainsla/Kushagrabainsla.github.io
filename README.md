# Kushagra Bainsla

Source for my portfolio, live at [kushagrabainsla.github.io](https://kushagrabainsla.github.io/).

It's a static site with no build step: `index.html` and `style.css`, published by GitHub Pages from `main`.

To preview it locally:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
